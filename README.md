# Shikirip Dark Theme

Темная тема для [shikimori.rip](https://shikimori.rip)

За основу взял стиль, который был сгенерирован через расширение Dark Reader. Потом чуть-чуть отредактировал его с помощью нейросетей. 

Сразу говорю: код далеко не идеальный, он вообще огромный и страшный. Так что если тут есть те, кто шарит — милости прошу, редактируйте, буду только рад!

Делал эту тему в первую очередь для себя. Хотел оригинальный интерфейс, но только в темной теме, а такой не нашел — пришлось самому что-то придумывать. Решил залить сюда, может, кому-то пригодится.

На телефоне тоже работает.
